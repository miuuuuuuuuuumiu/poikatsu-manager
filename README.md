# ポイ活マネージャー

ポイ活（ポイントサイト経由の副業案件）の案件・作業・利益をスマホで管理するアプリです。
スマホのホーム画面に追加して使うPWA（Webアプリ）で、データはすべて端末内（IndexedDB）に保存されます。ログイン・APIキー・月額料金は不要です。

---

## 1. 起動方法

パソコンで以下を実行します（Node.jsが必要です）。

```bash
npm install
npm run build
npm run preview
```

表示された `http://localhost:4173`（本番相当の確認用）、または開発中は

```bash
npm run dev
```

で起動した `http://localhost:5173` をブラウザで開いてください。

### スマホから開く（ホーム画面に追加する）

1. パソコンとスマホを**同じWi-Fi**につなぐ
2. パソコンで `npm run dev` または `npm run preview` を実行すると、ターミナルに

   ```
   ➜  Network: http://（パソコンのIPアドレス）:5173/
   ```

   のようなアドレスが表示されるので、そのアドレスをスマホのブラウザで開く
3. スマホのブラウザメニューから「ホーム画面に追加」を選ぶ
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「ホーム画面に追加」/「アプリをインストール」

一度ホーム画面に追加すれば、アプリのアイコンから直接開けます。オフラインでも画面は開けますが、パソコン側のサーバーが止まっていると最新版には更新されません（配布方法は今後のステップです）。

---

## 2. 基本的な使い方

- 下部メニューは「ホーム／案件／登録／予定／レポート」の5つです
- 設定はホーム画面右上の歯車アイコンから開きます
- 案件を登録すると自動で保存されます（保存ボタンを押す必要はありません）。画面上部に「保存中」「保存済み」「保存に失敗しました」が表示されます
- ポイントサイトの交換率は、設定画面の「ポイントサイトの管理」から入力してください（正確に分からない場合は未設定のままでかまいません。未設定の間は利益が「―」と表示されます）
- 案件を削除すると、すぐには消えず「ゴミ箱」に移動します。30日間は元に戻せます
- 初めて使うときや動作を試したいときは、設定画面の「サンプルデータを表示」で、承認待ち・非承認・付与済みなど状態の異なる案件を10件追加できます。試し終わったら「サンプルデータを削除」で片付けられます

## 3. バックアップ・復元の方法

設定画面の「データ管理」から行います。

| 操作 | できること | 注意点 |
|------|-----------|--------|
| CSV出力 | 案件の一覧をExcelなどで開けるCSVファイルとして保存 | 画像や個人情報チェックなど一部の項目は含まれません |
| CSV読込 | CSVファイルから案件を読み込み（新規追加・既存の更新） | 案件IDが一致するものは上書き、無いものは新規登録されます |
| JSON完全バックアップ | 案件・作業・ポイントサイト設定・**証拠画像**を含む、すべてのデータを1つのファイルに保存 | 機種変更やアプリの再インストール前に取っておくと安心です |
| バックアップから復元 | JSON完全バックアップのファイルを読み込み、データを復元 | 現在のデータに読み込んだ内容が上書き・追加されます |

**おすすめ**：定期的に「JSON完全バックアップ」を実行し、ファイルをパソコンやクラウドストレージに保存しておいてください。

## 4. 開発者向け情報

### コマンド

```bash
npm install      # 依存パッケージのインストール
npm run dev       # 開発サーバーを起動（http://localhost:5173）
npm run build     # 本番用ビルド（distフォルダに出力）
npm run preview   # ビルド結果をローカルで確認（http://localhost:4173）
npm run test      # 自動テストの実行
npm run lint      # コードチェック
```

### 使用技術と採用理由

| 技術 | 採用理由 |
|------|---------|
| React + TypeScript + Vite | 定番構成で保守しやすく、型安全でバグを早期発見できる |
| Tailwind CSS | スマホ優先のレスポンシブデザインを一貫して素早く実装できる |
| idb | IndexedDBを簡単に扱う軽量ラッパー。画像（Blob）も容量を気にせず保存できる |
| react-router-dom | 画面遷移の標準的なライブラリ |
| recharts | Reactに特化した無料グラフライブラリ |
| vite-plugin-pwa | Service Worker・マニフェストを自動生成し、オフライン対応とホーム画面追加を実現 |
| vitest | Vite標準のテストランナー |

状態管理ライブラリ・日付ライブラリ・フォームライブラリ・画像圧縮ライブラリは、規模に対して過剰なため使用せず、必要な分だけ自作しています。

### データの保存場所

すべてのデータはブラウザのIndexedDB（`poikatsu-manager`という名前のデータベース）に保存されます。サーバーには一切送信されません。ブラウザのデータを消去すると、バックアップを取っていない限りデータも消えます。

### フォルダ構成（抜粋）

```
src/
  lib/              # 計算処理・IndexedDB・CSV・バックアップなどのロジック
    repositories/    # データの読み書き（案件・ポイントサイト・作業・画像・設定）
  components/        # 画面部品
  pages/             # 7つの画面（ホーム・案件一覧・登録編集・予定・レポート・設定・ゴミ箱など）
```
